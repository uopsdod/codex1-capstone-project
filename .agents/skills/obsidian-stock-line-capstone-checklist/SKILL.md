# 美股通知知識庫：成果驗收

先讀取main交接的Vault與實際路徑，再透過Obsidian MCP讀回專案筆記、學習手冊與受影響的第三篇筆記。這是成果檢查，不重建筆記、不修改n8n、不發LINE或啟用任何排程。

逐項核對：
- 專案需求、工具分工、股票門檻、行情來源、執行步驟、排程、去重與訊息格式有來源。預設值不能當實際值，無證據填待確認。
- 行情成功、LINE API接受、本人手機收到、已發布啟用、自動Execution各自記錄；歷史結果與目前查核日期分開。
- 測試附可取得的Execution連結、日期、真實／模擬／歷史模式；缺連結標未提供。API接受不等於手機收到。
- 專案連回學習手冊與第三篇，首頁有專案入口；連結用實際路徑，目標存在且同名歧義已處理。第三篇確實不存在時，依main已交付的替代方案驗收，不虛構連結。
- 操作截圖是真實取得且附件存在，嵌入路徑正確；未提供則待補，不偽造附件。學員親眼看版面仍需本人確認。
- 更新保留原有實質內容及歷史測試，同名筆記／首頁入口未重複。只讀查核重複情況，不為驗收重寫兩次。
- 若已修改股票或門檻，筆記目前設定有修改後讀回證據，變更紀錄含前後值、原因、日期與測試；沒有實際改設定則該項待驗證，不擅自執行修改。
- 未包含秘密、完整收件人ID、私人信箱或敏感請求標頭；只記必要憑證名稱與用途。

用「項目／通過、未通過或待驗證／證據及限制」表回報，提供Obsidian工具回傳URI與需修正項。讀不到就未確認，不宣稱成功。缺陷交回main修復再驗，不默默覆寫人工修改。學員尚未查看截圖與內容時單列待本人確認；沒有實際變更紀錄不影響已完成基礎知識庫項目，但不能宣稱修改同步已驗證。
