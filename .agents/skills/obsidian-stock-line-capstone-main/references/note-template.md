# Capstone：我的美股跌幅 LINE 通知

## 專案需求與分工
- 想解決的問題、追蹤範圍與完成標準。
- Codex：建置、測試、維護；n8n：行情、條件與通知；Obsidian：保留知識與證據。

## 目前設定
- 查核時間與來源；若僅為歷史摘要明確標註。
- 股票／名稱、threshold_pct、嚴格比較規則、Data Table及固定鍵。
- 行情來源、紐約排程／時區、台灣對應時間。
- 本人 LINE、憑證名稱／用途、訊息格式、手動與正式去重差異。
- 草稿、實際啟用版本、最近自動執行狀態分列。

## 工作流步驟
1. 觸發並讀設定。
2. 取得並驗證日線。
3. 計算跌幅、判斷門檻與正式去重。
4. 產生卡片、LINE接受後記錄。

## 測試紀錄
每次標日期、真實／模擬／歷史重播、資料、門檻、預期、實際、Execution連結；行情／API接受／手機收件／排程分開。手機版面截圖用真實附件路徑嵌入。

## 問題與解法
現象、可查證原因、處理方式、處理後證據。推測另標待確認。

## 變更紀錄
日期、原因、修改前後、驗證證據、待確認項；保留舊紀錄。

## 下次修改檢查清單
- [ ] 股票、市場、幣別與門檻設定正確。
- [ ] 行情、判斷與卡片使用同一次設定。
- [ ] 啟用版本與草稿差異已核對。
- [ ] 手機收件與自動執行各自確認。
- [ ] 專案筆記已隨修改更新。

## 下次可用的交辦方式
請更新同一資料表中的股票或門檻，讀回確認，再更新本筆記的目前設定與變更紀錄，保留歷史測試；未測試的狀態明確標示。
