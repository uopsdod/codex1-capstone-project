# 筆記模板與驗收

依既有筆記格式調整，不必逐字照抄。缺證據就保留待確認。

筆記檔名：Capstone：我的美股跌幅 LINE 通知.md。Obsidian 已顯示檔名標題時，正文不重複加入同名 H1。

## 專案需求與分工
- 想解決的問題、追蹤範圍與完成標準。
- Codex：建置、測試、維護；n8n：行情、條件與通知；Obsidian：保留知識與證據。

## 目前設定
- 查核時間與來源；若僅為歷史摘要明確標註。
- 股票／中文名稱、跌幅門檻、一般判斷方式，以及實際工作流「通知門檻設定」節點。現行 JSON 不要求資料表或固定鍵。
- 行情來源；優先列出台灣每週二至六夏令05:00／冬令06:00，再補充底層紐約排程以自動切換夏令時間。
- 本人 LINE、憑證名稱／用途、訊息格式、手動與正式去重差異。
- 草稿、實際啟用版本、最近自動執行狀態分列。

## 工作流步驟
1. 觸發並讀設定。
2. 取得並驗證日線。
3. 計算跌幅、判斷門檻與正式去重。
4. 產生卡片、LINE接受後記錄。

## 測試紀錄
每次標日期、真實／模擬／歷史重播、資料、門檻、預期、實際、Execution連結；行情／API接受／手機收件／排程分開。手機版面截圖用真實附件路徑嵌入。

## 問題與解法
現象、可查證原因、處理方式、處理後證據。推測另標待確認。

## 變更紀錄
日期、原因、修改前後、驗證證據、待確認項；保留舊紀錄。

## 需要使用者完成的事項
只列本次仍需要本人完成的項目，已完成不重複列待辦：
- [ ] 在手機 LINE 確認正式通知是否收到，並告知 Codex。
- [ ] 需要保存手機畫面時，提供可用截圖；匯入附件由 Codex 處理。
- [ ] 在 Obsidian 親自查看筆記與連結，確認符合自己的需求。
- [ ] 做修改練習時，選擇想追蹤的股票或門檻並告訴 Codex。

技術設定、測試、查核及知識庫更新由 Codex 處理，不列為使用者操作事項。

## 下次可用的交辦方式
請 Codex 使用「美股跌幅 LINE 通知建置 Skill」修改同一工作流的股票或門檻，重新讀取確認，再使用「美股通知專案筆記整理 Skill」同步目前設定與變更紀錄，保留歷史測試。
